# Strategy and Prioritization

Use this reference when the user is choosing among competing paths and the answer depends on trade-offs rather than a single correct fact.

## Good fits

- comparing strategic options with different risk profiles
- ranking initiatives under limited capacity
- deciding whether to build, buy, partner, or delay
- evaluating market entry, expansion, or exit
- deciding what not to do

## First-pass framework selection

| Situation | Best first tool | Why |
|---|---|---|
| 2-5 comparable options | Decision matrix | Makes trade-offs explicit |
| Backlog or portfolio ranking | ICE scoring | Fast and good enough for early sorting |
| Probabilistic upside/downside | Expected value | Converts uncertainty into a comparable number |
| Big strategic bet | Scenario planning | Tests robustness across futures |
| Limited resources mean hidden trade-offs | Opportunity cost | Reveals the real no that comes with each yes |

## Decision matrix workflow

1. Name the decision and the options.
2. Choose criteria that actually drive the outcome.
3. Weight the criteria to 100 percent.
4. Score each option honestly.
5. Sum the weighted result.
6. Run a sensitivity check on the top weights.
7. If the winner flips easily, do not pretend the answer is firm.

## ICE workflow

Use ICE when you need a quick first pass.

- Impact: how much this moves the target metric
- Confidence: how reliable the estimate is
- Ease: how much effort and coordination it takes

Adjust the ranking if:

- one initiative unblocks another
- one item is a prerequisite for a bigger bet
- one item is cheap but strategically optional

## Expected value workflow

Use EV when the outcome can be stated as a range of payoff states.

1. List success, base, and failure cases.
2. Give each case a probability.
3. Assign the financial or strategic value of each case.
4. Compare EV, downside, and reversibility.
5. Do not let positive EV hide a catastrophic tail.

## Scenario planning workflow

Use scenario planning when a small set of unknowns drive most of the risk.

- identify the 2 variables that matter most
- define high and low states for each
- write the 4-quadrant world
- ask how each option behaves in every quadrant
- pick the move that stays acceptable across the widest set of outcomes

## Opportunity cost workflow

Whenever the decision consumes scarce capacity, ask:

- what are we saying yes to?
- what are we saying no to?
- what would the best alternative use of that time or money be?
- would we still choose this if we were starting today with no sunk cost?

## Market entry and build-vs-buy

For market entry or build-vs-buy, answer these before recommending:

- What is the minimum credible wedge?
- How strong is the local or incumbent advantage?
- What is reversible?
- What must be true for the move to scale?
- What is the exit or fallback path?

## Output checklist

1. State the real decision in one sentence.
2. Show at least 3 options plus do nothing when relevant.
3. Include the trade-off for each option.
4. Explain why the recommended path is better than the nearest alternative.
5. Name the dependency, gating assumption, or rollback condition.
