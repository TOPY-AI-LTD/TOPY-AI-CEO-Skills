# Example - Dashboard Priorities

## Prompt

> We can only work on two of these: onboarding from website, local file import, business plan edit flow, template edit flow, and billing polish. What should go first?

## A strong answer should

- use a decision matrix or ICE
- identify which items unlock the most downstream value
- distinguish user-facing polish from core capability
- include the opportunity cost of delay
- recommend a sequence, not just a rank order
- say what would reverse the ranking
