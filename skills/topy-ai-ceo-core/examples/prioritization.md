# Example - Prioritization Across Competing Initiatives

## Prompt

> We can only fund two of five initiatives this quarter. Prioritize them and explain the trade-offs.

## A strong answer should

- use ICE or a decision matrix instead of a generic opinion
- surface dependencies and sequencing
- call out opportunity cost explicitly
- distinguish reversible work from irreversible bets
- recommend a sequence, not just a ranking
- note what would make the ranking change
