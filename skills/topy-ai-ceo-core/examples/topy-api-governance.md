# Example - API Key Governance

## Prompt

> We have user API keys and admin API keys. Should we let more of the current API accept API key auth across profile settings and future AI CEO features?

## A strong answer should

- classify this as a stakeholder and risk decision
- separate user scopes from admin scopes
- call out blast radius and revocation requirements
- discuss where bearer auth is acceptable and where it is not
- recommend a rollout or segmentation strategy
- note what logging and audit trail are needed before expansion
