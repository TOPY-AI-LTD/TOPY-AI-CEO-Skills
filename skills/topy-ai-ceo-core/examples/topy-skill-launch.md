# Example - Launching a TOPY Skill Release

## Prompt

> We want to publish TOPY AI CEO Core as a public skills repo. Should we launch the core skill first, or wait until the product surface is broader?

## A strong answer should

- classify this as a strategic and operating-model decision
- compare launch-now, wait-and-broaden, and limited beta options
- call out the trade-off between reach and polish
- name the operational risk of shipping an underpowered public surface
- include what evidence would justify a public release
- recommend a decision gate rather than a vague "soon"
